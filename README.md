# P&L Report – Excel Project

An end-to-end P&L and Sales Performance Reporting project created in Excel while learning advanced Excel tools and techniques.

## 📊 Project Overview

This project uses multiple datasets to build financial and sales performance reports for AtliQ Hardware.

The reports provide insights into:

- Net Sales
- COGS
- Gross Margin
- Gross Margin %
- Year-over-Year Sales Performance
- Market Performance vs Target
- Customer Sales Performance
- Monthly & Quarterly P&L Analysis

## 🛠️ Tools & Techniques Used

- **Power Query** – Data cleaning, transformation and preparation
- **Power Pivot** – Data modelling and relationships
- **DAX** – Creating calculated measures
- **PivotTables** – Interactive reporting and analysis
- **Conditional Formatting** – Visual representation of performance

## 📊 Reports Included

### 1. P&L by Fiscal Year
Provides a yearly view of:
- Net Sales
- COGS
- Gross Margin
- Gross Margin %
- YoY comparison

### 2. P&L by Month
Provides monthly and quarterly analysis of:
- Net Sales
- COGS
- Gross Margin
- Gross Margin %
- Year-over-Year sales comparison

### 3. Customer Net Sales Performance
Compares customer-level Net Sales across 2019, 2020 and 2021, with YoY performance indicators.

### 4. Market Performance vs Target
Compares 2021 Net Sales against the 2021 target, including absolute and percentage variance.

## 🔄 Workflow

Raw Data → Power Query → Data Model → DAX Measures → PivotTables → Reports

## 🎯 Learning Outcome

This project helped me gain practical experience in using Excel for **data transformation, data modelling, financial analysis and business reporting**.

It was created as part of my **Excel learning journey** and was one of my first hands-on projects combining Power Query, Power Pivot and DAX.
